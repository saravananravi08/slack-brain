### Design decisions taken (and why), all within accepted decisions

1. **New set rather than edits to `docs/architecture/contracts/`.** That set is change-controlled by T004 and outside my write scope; D013–D015 conflict with four of its clauses. Supersession is documented in `README.md` §1 and scoped to `ch:` boundaries in P06/P07 only — DM handling, archive import, retrieval scope, and the D004/`deleteMessages` primitives are untouched.
2. **Separation enforced in the type signatures,** not by convention: `responseDecision` cannot accept a `CaptureDecision`, `captureDecision` cannot accept a `PolicySnapshot`, and `CanonicalSender` carries no eligibility field. A procedural rule here erodes; a signature does not.
3. **`self_authored` denies before `non_human_sender`** rather than being folded into it. Gist replying to itself is the shortest possible loop and must deny even if sender-class resolution is wrong about everything else.
4. **Sender-class resolution is Gist → Kilo → system → bot → app → human,** matched on configured IDs only, never display name or text. A renamed bot must not be able to classify as a human.
5. **`empty_text` is not a capture denial** in this set (it is in v1). An attachment-only message carries `text: ""` and real content in `files`; the v1 skip would drop it. A wholly empty message is still captured so the channel sequence has no holes.
6. **No tombstone on delete-ignore.** The v1 tombstone suppressed re-ingestion after a hard delete. Nothing is deleted here, so a tombstone would only suppress *legitimate* redelivery of a message Gist still holds. Copying the v1 delete path would have been wrong in a way that looks right; fixture `delete_then_redelivery_is_not_suppressed` pins it.
7. **An edit whose target is unstored inserts** (at/after the floor) rather than no-op. Slack can deliver an edit without the original across a reconnect gap, and a no-op loses the message. Apply-if-newer stops a late original from regressing the text; below the floor it stays `ignored`, so this cannot become a backfill path.
8. **`DerivedInvalidation` emitted in P06, consumed in P07.** CM-FR-026 straddles the phases; without a P06-side signal P07 has no way to know which summary/observation text quotes retracted wording. Recorded as an integration rule with named owners rather than left implicit.
9. **Capture floor comparison never uses a float.** `compareMessageTs` pads the fractional part for *ordering* while `message_key` keeps the verbatim string for *identity*, so `.0002` / `.000200` order equal but remain two distinct messages.
