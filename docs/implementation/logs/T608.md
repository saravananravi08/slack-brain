# T608 — Edit-to-mention response trigger

## Outcome

Implemented D019 on the P06 Slack runtime.

- Registered `onMessageUpdated` when P06 capture ports are enabled.
- Routed only an `updated` human root edit that newly adds `<@Gist>` through existing `channel.handlers.onNewMention`.
- Kept bot/app edits, reply edits, replayed deliveries, existing mentions, denied users, and non-updated mutations response-silent.
- Preserved T605 mutation handling and in-place storage replacement.
- Reused durable delivery dedup before mutation and response evaluation.
- Preauthorized edit candidates before mention routing; denied edits post no authorization response and accepted edits are not authorized twice.

Implementation commit: `86e33df` (`feat(T608): edit-to-mention response trigger per D019`)

6. Unauthorized sender → no response.
