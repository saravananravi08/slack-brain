- Decisions/assumptions:
  - **Socket Mode is set explicitly.** The adapter's default is `mode: "webhook"`; FR-SLK-011 requires Socket Mode. A structural assertion on the adapter pins it, because a silent regression to webhook would present as "Slack events stopped arriving" rather than as an error.
  - **Credentials are injected, never env-autodetected.** The adapter factory supports env auto-detection; using it would let a misconfigured process connect with whatever happened to be in the environment, against FR-OPS-002. A test asserts no `process.env` read anywhere in the module. Environment parsing remains T102's.
  - **Authorization and generation are required injected ports with no defaults.** A missing authorizer is a construction error rather than an open door (INV-1). This also keeps T203 and T105 out of this module's import graph; a test asserts that.
  - **Deny handling is split by scope.** Channel-, workspace-, and sender-scoped denials produce no reply at all (FR-SLK-010 — replying would mean Gist speaking in a channel it is not approved for, and would confirm its presence to an outsider). User-scoped denials produce the single generic line, which never explains why. Recorded here because the error contract specifies the string but not which denials are silent.
  - **`isBot === "unknown"` is treated as non-human.** The Chat SDK types allow that third value; treating it as human would let an unidentified sender drive Gist.
  - Slack `ts` is kept a verbatim string end to end, with a test on the precision pair from `fixtures/slack-events.v1.json`.
  - Subscription happens only after a positive authorization decision, so Gist never subscribes to a thread it may not answer in.
  - One TypeScript narrowing was needed at the `Chat({ adapters })` boundary: `SlackAdapter.botUserId` is `string | undefined` where the `Adapter` interface requires `string`, which conflicts under T101's `exactOptionalPropertyTypes: true`. This is a published-type mismatch, not behavioral — the adapter resolves its bot user ID during `initialize()`. Narrowed locally with a comment rather than relaxing compiler options, which are T101's scope.
